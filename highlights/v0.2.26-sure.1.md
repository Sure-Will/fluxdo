这一版是 Sure fork 的第一个独立修订版，基于原作者 FluxDO v0.2.26。主要处理了 AI 对话、macOS 粘贴、长时间刷帖的内存占用，以及话题刷新在积压很多更新时容易失败的问题。

### 🧠 AI 对话

- DeepSeek V4 Flash 的思考档位调整为 Off、Auto、Low、High、Max，选择结果会按模型实际支持的方式发送，不再出现界面档位和请求行为对不上的情况。
- 选择「全部帖子」后，FluxDO 会先确认需要的楼层已经加载完整，再把问题发给模型；加载失败时不会清空输入内容，可以直接重试。
- AI 对话的发送快捷键、输入框高度和消息滚动做了补强，长回答生成时更容易跟住当前位置，也不会因为列表重建突然跳走。
- 已完成的 AI 回答、聊天摘要和话题摘要现在可以拖选其中一部分再复制；仍在生成的内容会暂时关闭选区，避免流式更新打断选择。

### 📋 编辑与剪贴板

- 修复 macOS 回复编辑器按 `Cmd+V` 没有反应的问题。编辑器现在只执行一次完整的粘贴流程：剪贴板里有图片时上传图片，否则在当前光标位置插入文本。
- 右键菜单粘贴和键盘粘贴共用同一条处理路径，避免默认文本粘贴与图片检测同时读取剪贴板，造成丢内容或重复插入。
- 分享图预览新增「复制」按钮，可以直接把生成的 PNG 图片写入系统剪贴板，不必先保存到相册再使用。

### 🖼️ 图片与内存占用

- 动图在应用切到后台、窗口长时间失去焦点或页面被隐藏后会释放已解码帧；回到前台时按需恢复，减少长期驻留的内存。
- 首页、轮播图、图片网格和帖子正文中的图片会跟随当前页面状态卸载隐藏页面的图片流，减少多栏界面和持久页面同时保留大量图片的情况。
- macOS 的图片缓存上限从默认的 256 MB 收紧到 128 MB，非活动页面也会暂停不必要的动画更新，长时间刷图时内存增长更克制。

### 🔄 话题刷新

- 桌面端和平板端新增独立的话题刷新入口，刷新与创建话题各自保留固定位置，不再因为滚动状态互相替换。
- 长时间未打开应用时，单次增量刷新只处理最近活跃的 50 个话题，避免把上千个话题编号塞进一次请求。
- 刷新过程中再次到达的新回复会继续保留，失败的刷新也不会把提示直接清空，网络恢复后可以再次尝试。

### 🖥️ macOS 说明

- macOS 版改用长期稳定的 FluxDO 自签身份和全新的 Keychain 服务名。登录令牌、AI 服务密钥等敏感数据重新由系统钥匙串保护，后续使用同一签名覆盖升级时不会因为每次构建身份变化反复弹出授权框。
- 过渡版本写入本地偏好设置的敏感数据，会在首次读取时先写入新 Keychain 并读回核验，成功后再删除明文；旧 adhoc 构建留下的 Keychain 项不会读取或修改，避免触发旧 ACL 授权。
- macOS 安装包仅支持 Apple Silicon，使用稳定自签证书但未经 Apple Developer ID 公证；首次打开时可能需要在 Finder 中右键选择「打开」。

### 🤖 Android 说明

- Android 安装包仅包含 `arm64-v8a`，适用于大多数近年的 64 位 ARM 手机和平板。
- Sure fork 使用自己的稳定签名，与原作者安装包的签名不同。已经安装原作者版本时，需要先卸载原版再安装；以后 Sure fork 的后续版本可以直接覆盖升级。
- 应用内安装包更新只跟随 Sure fork Release，确保 Android 下载到同一签名通道的 APK；原作者版本变化会在后续 Sure Release 及其更新日志链接中说明。
